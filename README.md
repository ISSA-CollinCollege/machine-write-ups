# machine-write-ups

This space is used to showcase professional write ups for penetration tessting, digital forensics, and threat intelligence reports.

### Ethical Obligation Notice
- All write ups must be made from machines/devices that have had explicit autorization granted. These include, but are not limited to: home labs, HAck the Box machines, and/or TryHackMe labs.
- If the write up was perfomed on a machine that you do not have authorization, it is considerd a crimnial act and it will be taken down.
- Thank you for keeiping the "ethical" in "ethcial hacking"!

### Examples
- Examples of write up formats can be found in thr repository directory.
- These are just suggestions. If you have/find better formats, please share!
- Try to keep the write up as professional as possible
